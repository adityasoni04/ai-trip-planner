# Xplore.ai — AI Trip Planner

Personalised itineraries, hotels, budget, map and packing list for any destination, generated by Google Gemini.

**Stack:** React 18 · Vite · Tailwind · Firebase Auth + Firestore · Gemini (free tier) · OpenStreetMap/Leaflet · Wikipedia photos

Only **two services need keys**: Firebase and Gemini. Maps, place search and photos use free, keyless APIs.

## Features
- Google sign-in (Firebase Auth)
- AI trip generation: day-by-day itinerary, hotels, budget breakdown, food, tips, packing list
- Place autocomplete (OpenStreetMap), interests, start date, currency, special requests
- Interactive map with numbered, day-coloured pins
- Packing checklist with saved progress
- Share via public link (toggle public/private), print / save as PDF
- Trip search & delete, light + dark mode, responsive UI

## Setup

1. `npm install`
2. Copy `.env.example` to `.env` and fill it in:
   - **Gemini:** create a free key at <https://aistudio.google.com/apikey> → `VITE_GEMINI_API_KEY`
   - **Firebase:** [console.firebase.google.com](https://console.firebase.google.com) → create a project → add a **Web app** → copy the config values into the `VITE_FIREBASE_*` vars.
3. In the Firebase console:
   - **Authentication → Sign-in method:** enable **Google**.
   - **Authentication → Settings → Authorized domains:** make sure `localhost` and your deployed domain are listed.
   - **Firestore Database:** create a database (production mode), then paste the contents of `firestore.rules` into the **Rules** tab and publish (or run `firebase deploy --only firestore:rules`).
4. `npm run dev` → <http://localhost:5173>

## Deploy
`npm run build`, then `firebase deploy` (Firebase Hosting; SPA rewrite already configured) or deploy `dist/` to Vercel/Netlify with the same env vars.

## Security note
Vite env vars are bundled into the browser. Firebase web config is meant to be public (Firestore rules protect data). For the Gemini key, set an HTTP-referrer restriction in Google Cloud Console → APIs & Services → Credentials, or move the call behind a Cloud Function for production.
